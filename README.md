# 먼작귀 번역기

한글로 쓰면 먼작귀(ちいかわ) 친구들 말투로 바꿔 주는 팬메이드 번역기예요.
치이카와, 하치와레, 우사기, 시사, 쿠리만쥬, 랏코, 모몽가가 같은 말을 각자 자기 말투로 말해요.

스케치북에 색연필로 칠한 느낌으로 꾸몄고, 캐릭터 그림도 직접 그린 팬아트예요.

## 말투는 이렇게 정했어요

원작 만화와 애니메이션 대사(나무위키, ピクシブ百科事典, 애니 회차 요약, 팬 대사 모음)를 조사해서 캐릭터마다 규칙으로 만들었어요.

| 캐릭터 | 말투 |
|---|---|
| 치이카와 | 문장으로 말하지 않아요. 감탄사(와아…, 후!!, 히익…!!)와 들은 낱말의 앞 한두 음절만 따라 해요. `라면 먹으러 갈래?` → `라…? 와…! 후!!` |
| 하치와레 | 말끝을 끊거나(먹잣, 고마웟) 늘이고(그렇지이), 말 순서를 뒤집어요. 위기에는 `어떻게든 돼라~앗!!`, 윗사람에게는 존댓말. |
| 우사기 | `우라`, `야하`, `푸루야`, `하아?` 같은 소리만 내요. 소리의 길이와 억양은 원래 문장을 따라가요. |
| 시사 | 존댓말 끝을 길게 늘여요(배고파요~!, 열심히 할게요~!!). 기분은 `기쁘시사~` 같은 말장난으로, 인사는 미야코 말 `응먀—치`. |
| 쿠리만쥬 | 독자에게는 대사가 들리지 않는 캐릭터예요. 몸짓과 한잔 넘긴 뒤의 `하아—ㅅ!`이 전부. |
| 랏코 | 짧고 단단한 반말(~다., ~냐?)에 핵심어를 맨 뒤로 보내요. `망쳤다… '시험'` |
| 모몽가 | 명령하고 칭찬을 요구해요. `칭찬해라앗!`, 싫을 땐 `이—야—야다야다!!` |

같은 문장도 **다시**를 누르면 다르게 말해요.

## 실행

빌드 과정이 없는 정적 사이트예요. 아무 정적 서버로 열면 돼요.

```sh
python -m http.server 8000
# http://localhost:8000
```

`?t=하고 싶은 말` 주소로 바로 공유할 수 있어요.

## 테스트

```sh
npm test
```

## 구조

- `js/korean.js`: 문장 끝 분석과 어미 활용 (반말·존댓말, ㅂ·르 불규칙, 받침에 따른 조사)
- `js/mood.js`: 문장에서 감정과 상황 읽기
- `js/speakers/`: 캐릭터별 말투 규칙
- `js/art.js`, `js/sketch.js`: 캐릭터 그림과 색연필 빗금, 흔들리는 연필 선

## 알림

비공식 팬메이드예요. 먼작귀(ちいかわ)와 캐릭터의 권리는 나가노(ナガノ)에게 있어요.
